# CLOSER Call Spine

Walks a sales call through Clarify -> Label -> Overview -> Sell the vacation -> Explain away concerns -> Reinforce, with the contrast built in the Overview.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Skip the Overview and the contrast never forms. A yes without a booked kickoff (inside 48h) is an intention, not a close. Prep and notes tool — no step is performed on a live call by the agent.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the CLOSER Call Spine to help me: walks a sales call through Clarify -> Label -> Overview -> Sell the vacation -> Explain away concerns -> Reinforce, with the contrast built in the Overview — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
